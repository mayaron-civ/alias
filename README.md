# Alias

## Запуск

`start.bat` — откроется браузер, в окне консоли будет адрес для телефона.
Можно и просто открыть `index.html`, но тогда с телефона не зайти.

С телефона: тот же Wi-Fi, вбить адрес вида `http://192.168.0.5:8777`.
В Chrome/Safari — «Добавить на главный экран», дальше открывается как приложение.

## Режимы

- Классика — 2501 обычное слово
- По темам — 17 тем, по умолчанию не выбрано ничего
- Boys vs Girls — парням «женский» банк, девчонкам «мужской», переключатель меняет местами
- Рисунок — фото под ширмой, объясняющий описывает, команда рисует
- Чья фраза — цитата из чата, назвать автора

Сложность: Лёгкий (зелёный), Нормальный (синий), Сложный (фиолетовый), Спёкшийся (оранжевый).
Цвет виден и на карточке во время игры. Можно выбрать несколько уровней сразу.

## Управление

Телефон — только свайпы: вправо засчитать, влево мимо. Кнопок нет.
Компьютер — кнопки, `←` `→` и пробел.
Крестик слева вверху во время хода заканчивает ход досрочно и открывает итог.
На экране итога карточки переключаются нажатием, а кнопка `?` показывает
короткую справку по слову из Википедии (нужен интернет).

Переключатель «Подсказки» в настройках выводит такой же `?` прямо на карточку —
объясняющий может подсмотреть значение в любой момент, не прерывая ход.
Справка подгружается заранее, открывается сразу.

Названия команд подставляются случайно из списка в `TEAM_NAMES` в начале `app.js`.
Кнопка «Перемешать» берёт новую пару.

За 3, 2, 1 секунду до конца бьёт маримба, в конце — нисходящий аккорд с басом.
Слышно обеим командам: последнее слово могут угадывать все.
Звуки синтезируются на лету (WebAudio), файлов нет; громкость сведена так,
чтобы конец хода был заметно громче остального.

## Файлы

```
index.html  app.js  manifest.json  start.bat
data/words-*.js    слова
data/phrases.js    фразы из чата
data/photos.js     список фото
photos/            фото
```

## Свои слова

```js
ALIAS_WORDS.тема = [ [лёгкий], [нормальный], [сложный], [спёкшийся] ];
```

Добор лежит в `data/words-more-1..4.js` — там массивы дописываются к основным.
Новая тема: массив + строка в `THEMES` в начале `app.js` + подключить файл в `index.html`.

## Данные

11 394 слова в 19 банках. Фото и фразы из экспорта чата: фото ужаты до 1000 px,
скриншоты отсеяны; фразы 22–165 символов, без ссылок, медиа, пересылок и повторов,
авторы с меньше чем восемью репликами не участвуют.
